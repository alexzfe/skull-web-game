# Contributing

Thanks for your interest in Petals & Bones!

- **Issues are welcome**: bug reports, rule mix-ups, ideas, and phone layout glitches (a screenshot helps).
- **Pull requests are welcome**, but they're merged at the maintainer's discretion. For anything bigger than a small fix, opening an issue first to talk it through saves everyone time.
- **Run `npm test` before opening a PR** and make sure it passes. CI runs the same tests on every pull request.
